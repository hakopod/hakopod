# Database icons

The dashboard serves product icons locally. Product names remain in adjacent
text and the images are decorative to assistive technology.

The Oracle wordmark is from [Devicon v2.17.0](https://github.com/devicons/devicon/blob/v2.17.0/icons/oracle/oracle-original.svg),
stored at `web/public/icons/oracle.svg`. It identifies Oracle Database without
implying an endorsement. Oracle Database Free is proprietary software.

The existing PostgreSQL, Redis, MySQL, MongoDB and ClickHouse SVGs are retained.
